# Client Audit Lite

A free Claude plugin that audits a web page for SEO and AI-search visibility and writes a scored report in Arabic or English.

The plugin lives in [`client-audit-lite/`](client-audit-lite/); its own README explains what it does, what it reads and what it does not measure.

## Install

Requires Claude Code 2.1.275 or later.

```
/plugin install client-audit-lite --marketplace reemalfadly/client-audit-lite
```
